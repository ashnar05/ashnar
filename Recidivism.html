Overview

This project focused on predicting recidivism risk using a publicly available dataset of incarcerated individuals’ demographic, behavioral, and correctional history. I developed and compared multiple machine learning models (Random Forests, a Sparse Linear Integer Model, and a Neural Network) to evaluate predictive accuracy, interpretability, and fairness across demographic subgroups. This work demonstrates my ability to handle the full ML pipeline from scratch: from feature engineering and data cleaning to model development, evaluation, and ethical analysis.

Technical contributions

Data preprocessing & feature engineering

  • Cleaned and imputed missing values across behavioral and demographic features using SimpleImputer.
  • Encoded categorical variables with LabelEncoder for ML compatibility.
  • Engineered features capturing prior arrests, conviction episodes, supervision levels, drug test results, and employment stability, transforming raw variables into predictive signals.
  • Created binary thresholded variables (e.g. felony arrests > 3, percent employed > 50%) to support interpretable linear models.

Model development

  • Random Forest Classifier:
    • Trained a 500-estimator ensemble model on 40+ features.
    • Achieved solid predictive accuracy, with probability-based outputs suitable for risk ranking.
    • Evaluated subgroup performance using confusion matrices by various metrics, revealing disparities in false positive/negative rates.
  • Sparse Linear Integer Model (Supersparse):
    • Applied FasterRisk optimization to derive a compact, interpretable scoring system.
    • Restricted coefficients to integer weights for transparency in real-world decision-making (risk scorecards).
    • Balanced predictive performance with interpretability, producing simple rules for parole denial risk.
  • Neural Network (Deep Learning):
    • Built a feedforward neural network with two hidden layers (60 units each, sigmoid activation).
    • Implemented using TensorFlow/Keras, trained with stochastic gradient descent on 50+ features.
    • Evaluated on test data, achieving competitive accuracy while demonstrating ability to scale to more complex architectures.

Model evaluation & fairness analysis

  • Compared accuracy, AUC, and error types across models.
  • Visualized subgroup confusion matrices to assess fairness.
  • Generated risk probability outputs and Kaggle-style CSV submissions for external benchmarking.

Impact

Through this project, I gained the ability to design, train, and critically evaluate ML models in domains where fairness and interpretability are essential. By implementing both advanced ensemble methods and interpretable sparse models, I learned technical versatility, rigorous data science practice, and awareness of ethical AI challenges.
